# Log File Analyzer has no third-party dependencies.
#
# Every module in this project (log_analyzer/, scripts/, tests/) uses
# only the Python standard library: re, dataclasses, enum, datetime,
# collections, pathlib, argparse, json, csv, random, tempfile, unittest.
#
# This file exists because a reviewer opening the repo expects to find
# it -- an empty repo with no requirements.txt at all could look like
# an oversight rather than a deliberate zero-dependency design choice.
#
# To run this project, you only need Python 3.10+ (built and tested
# against Python 3.14.4) -- no `pip install` step is actually required.
